QT Database v1.0.0 paired reader analysis. Source: https://physionet.org/content/qtdb/1.0.0/ . Run python reader.py with a recent Python 3, numpy, requests and wfdb (tested WFDB 5.0.0). The script downloads 11 official headers and both final clinician annotation streams for each record (33 files in total) and generates the paired-event CSV, record denominators, SHA-256 list and 10,000 record-resampled intervals. No model is trained or tested here. QTDB was originally described by Laguna et al., Computers in Cardiology 1997, doi:10.1109/CIC.1997.648140.
