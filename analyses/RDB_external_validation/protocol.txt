RDB v4 external transport experiment | frozen local analysis specification
Written before running either head on RDB. This local design record is not a public preregistration.

Question: does the difference in six-boundary performance between parameter-matched KAN and GELU heads persist in a second external source? Do not select models on RDB. Test the existing LUDB-trained five-fold ensembles for the original training seeds 1 and 2 separately. Neither seed is privileged; the primary contrast is the arithmetic mean of their paired differences. Bootstrap intervals condition on these two fitted training repetitions. No retraining or threshold fitting.

Cohort: RDB v4 full single-centre Chapman-derived cohort, all eligible 10-second ECGs, fixed lead II, clinical reference in *.ii.txt. One source tracing per original Chapman record ID (retain lexically first when duplicated); flag and deduplicate equal native lead-II waveforms. Do not call source-record IDs patient IDs. Read the source rhythm (e.g., the RDB 'VT' prefix maps to Chapman SVT). The authors' fixed cohort composition is retained. This is unseen by the LUDB-only checkpoints; the wider project used RDB in a separate training experiment. Do not present the entire project as blinded to RDB.

Preprocess: native 500 Hz, use second CSV column. Resample to 250 Hz with polyphase filtering, 0.5-40 Hz second-order Butterworth bandpass (forward/backward), standardize by median and IQR/1.349, fall back to SD. Flag and omit unreadable, missing, non-finite, flat, wrong-length or unannotated records for both models. Five-fold mean class probability, 2048-sample windows with original Hann blend and final end-aligned window, argmax, merge gaps <5 samples, minimum P/QRS/T runs 10/10/15 samples. No peak pseudo-labels.

References: retain the native fractional indices for onset and inclusive offset (milliseconds = index x 2). Remove malformed, reversed/zero-length, out-of-range intervals; remove duplicate marks per type. Omit only the boundary touching 0 or 4999 on a non-degenerate edge-crossing interval. Omit predicted onsets touching the start and offsets touching the end of the model grid as unobservable. Score the common span from first admissible mark minus 150 ms to last plus 150 ms clipped to the recording. Count all in-span detections, including when that ECG has no reference of that type. Closest-first, one-to-one matching by endpoint inside each source record, with native timing and stable ties. Predefined primary tolerance 150 ms; 40 ms sensitivity analysis. Absolute timing error summaries are conditional on matched pairs. Describe unmatched P onsets per annotated minute in AF/AFL (avoid interpreting them as clinician-adjudicated false alarms).

For each head and seed pool endpoint TP/FP/FN across records, compute six endpoint F1 values, then take their unweighted mean (macro-F1). Average seed-specific metrics for summaries. Paired percentile 95% intervals use 2,000 draws of source ECGs jointly across heads and seeds (fixed seeds 1/2, composition of source rhythms stratified by the eight original rhythm strata). Use global primary conclusion; per endpoint, tight tolerance and rhythm differences are descriptive. Compare head outputs on records with equal assessment scope. Report reference construction, audit denominator, comparator direction and uncertainty including null results. The corpus lacks separate observer replicates for this experiment. Data source doi:10.6084/m9.figshare.28892186.v4; dataset article doi:10.1016/j.eswa.2025.127955.
