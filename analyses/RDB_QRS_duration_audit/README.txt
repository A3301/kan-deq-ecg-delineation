External lead-II QRS duration audit

This package reproduces the single-lead interval analysis offline. Included are the eight resulting segmentation masks from the four frozen models and two training seeds, the original published native lead-II annotation files for the 2,398 included source ECGs, record/annotation QC, scoring code and per-event/per-record results. The larger RDB architecture accompanying archives contain the weights and raw-waveform inference programs for rebuilding these masks. The masks in this package are byte-for-byte the same as in the analysis directory. The quantification requires no PyTorch installation, CUDA hardware or model refitting.

From the extracted folder, with Python, NumPy and pandas installed, run:

python qrs_duration.py --rdb data/RDB_lead_II_labels.zip --heads heads --equilibrium equilibrium --out rerun
python verify_qrs.py --rdb data/RDB_lead_II_labels.zip --heads heads --equilibrium equilibrium --out rerun

The included label ZIP copies each original ann_txt/ID.ii.txt member from RDB v4 without altering its bytes. It omits other leads and the raw waveforms. The study ran against the full official dataset.zip, so its full-archive input digest differs from the compact subset digest. Native member hashes and source/subset hashes are in label_provenance.json. The same commands accept the full original RDB v4 dataset.zip. Per-event, per-record and summary statistics are the same with either input.

Delineation methodology paper: Liu et al., Expert Systems with Applications 283 (2025), article 127955, https://doi.org/10.1016/j.eswa.2025.127955 .

results/duration_summary.csv has pooled beat-weighted MAE and signed bias, paired contrasts and source-record cluster interval estimates. Positive bias denotes a longer prediction. Negative group differences in MAE favor the first model. results/coverage.csv lists eligible reference and predicted complexes, matches, misses, unmatched predictions, coverage and precision for every fitted model run. The four-way common set is specific to each model pair and is identical across its two fitted seeds. results/duration_by_seed.csv retains individual training runs. results/rhythm_duration.csv tabulates descriptive results by source rhythm. Matching failure remains visible in coverage. Conditional estimates alone do not capture error on missed complexes. All values refer to the supplied lead-II tracing and annotation convention. A clinical global twelve-lead QRS interval and prospective clinical action were outside the study.
