Disjoint-lead sensitivity analysis of QRS undermeasurement | 25 November 2026

Local follow-up after the parent study. The previously available global-12, reference-width-stratified results are known. This analysis rule was recorded before calculating any of the new six-lead exposure or outcome values. Do not tune the lead selection, interval threshold, algorithm or cut point after seeing results.

Question. Does undermeasurement persist when an event's reference width group and the interval used to score model error are based on different leads? A source-header feasibility check before analysis found only four records marked “Complete left bundle branch block.” and four marked “Complete right bundle branch block.” (all ages). We therefore use complementary lead sets and do not estimate diagnostic-group effects.

Population. Start with all 200 LUDB records, restrict to age >=18 as documented in each source header. Retain exactly the eligible native 12/12 reference QRS groups and intersection-of-annotation-span rule in the parent protocol. The age subgroup and denominator thus match its adult global-12 table. This source-beat visibility restriction is common to both directions. Archive links to the same six frozen RDB-trained fits (KAN/GELU, seeds 1–3), native annotated references and outputs.

Exposure and outcomes. Define one grouping width from the earliest manual onset and latest manual offset among the six limb leads on the same beat (I, II, III, aVR, aVL, aVF); assign groups <120 or >=120 ms. The endpoint uses the other six leads (V1–V6): construct a manual earliest-to-latest interval, and independently group model detections among the target six leads without their manual boundaries or any grouping-lead output. Require all six target leads to contribute a predicted QRS. Reverse directions without changing anything: precordial grouping and six-limb-lead measurement. A six-lead 120 ms cut is a descriptive grouping variable based on the previous sensitivity and not a clinical conduction diagnosis. Both directions are reported irrespective of direction or significance; no pooling across directions.

Match target reference and target model intervals on positive overlap and midpoint difference <=150 ms, exactly one-to-one, before dividing matches by the reference grouping width. Retain parent common observability span and acquisition-edge rules. Target predictions not matched to the retained references cannot be assigned a width stratum and are not included in success numerators. Link to the parent archive for all-predicted PPV and extras; the current question concerns internal-reference width grouping. Units of analysis are native beats and adult records, not separate leads.

Calculate within each direction, grouping width and head: (1) the primary signed target-duration error on each model's matched beats, prediction minus target reference (ms), (2) fraction of all eligible reference beats successfully returned with absolute duration error <=20 ms, (3) matched absolute duration error (ms) and detection proportion. Output denominators, median reference widths, and error/coverage per seed plus three-fixed-seed averages. Calculate the >=120 minus <120 difference in average signed error as a paired contrast in each direction and head. Resample adult participants jointly across all beats, groups, models and seeds (10,000 draws, RNG seed 20261125). Report percentile 95% intervals conditional on weights; strata may share people. Wider-stratum signed bias and the within-head wide-minus-narrow contrast both inform interpretation. No multiplicity or cross-patient clinical diagnostic claims. Distinct numerical boundaries remove direct subtraction of a quantity that defines the stratum, but underlying cardiac morphology, reference acquisition, beat grouping and annotation protocol are shared. Findings apply only to complete all-12-lead reference beats and six-lead target intervals, neither is an independently physician-adjudicated global reference.
