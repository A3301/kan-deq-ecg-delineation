Statistical replay from saved model outputs

Run python reanalyse.py in the extracted directory. The compact archive includes every input for this command, including the forward-pass predictions from the two cleaned BUT segments. The command writes h3_results.csv, h2c_record_results.csv, deq_external_results.csv and deq_range_support.csv. It checks the frozen protocol hash, the LUDB comparator and exact agreement of the primary-benchmark H3 bootstrap results with the primary-benchmark saved table. Tested using Python 3.12, NumPy 2.5.3, pandas 3.0.6, SciPy 1.18.1 and scikit-learn 1.9.1. No Internet connection is needed. The original LUDB, Zhejiang and ISP per-lead files contain model outputs; this statistical replay does not train a model or infer new predictions on those cohorts.

H3 table groups

full_corrected uses all 50 segments and all 45 source records. For the two segments with zero valid P events, run the saved fold ensembles on both full leads and count every predicted P as an FP against the empty reference, in accord with the original empty-reference window rule. The main results must cite this group. as_run retains the primary-benchmark invalid −1 N entries and serves as an audit trail only. valid_P_segments excludes both segments completely, leaving 48 segments and 43 source recordings. Counts refer to pooled lead-level events. Intervals are paired source-record bootstrap percentile intervals in percentage points. The subject is the source recording; the archive does not supply universal patient IDs across source databases. The three originally planned tests share a Holm family. Both the primary and head-control sentinel prediction CSVs include the 250-Hz positions of individual predictions.

Independent raw replay (optional)

The separate raw-replay archive includes reviewed numerical model definitions, raw data for BUT 08 and 48, chosen learning rates, stage-1 weights and both seed-specific controls. Install torch and wfdb as well (tested with CPU PyTorch 2.14.1, WFDB 4.3.0). Run python replay_sentinels.py, then python replay_sentinels.py --head-weights inputs/head_weights, then python reanalyse.py. Each forward pass uses weights_only=True. The four unaugmented model ensembles use the source-selected folds and the original 2,048-sample sliding window, 1,024-sample hop, tapered probability averaging, and the original 250-Hz filter, robust scaling and P postprocessing rules. The supplemental controls use the same protocol at each seed. Extra waveform downloads are not necessary for the two affected segments. The other 48 segments are represented by the original per-source TP/FN/FP counts.

Raw-waveform source and attribution

Segments 08 and 48 are from the Brno University of Technology ECG Signal Database with Annotations of P Wave (BUT PDB), version 1.0.0, by Lucie Maršánová, Andrea Nemcova, Radovan Smisek, Lukas Smital and Martin Vitek (2021), https://doi.org/10.13026/hwvj-5b53. Data are distributed under CC BY 4.0. The original README and license are supplied. Source 08 derives from MIT-BIH Arrhythmia Database record 203. Source 48 derives from Long Term AF Database record 62. The raw-replay archive preserves the distributed waveform and annotations. Model weights and saved model outputs were provided by the authors in their research archive. The compact archive contains derived statistics without raw ECG signals.

DEQ endpoints and uncertainty

The externally tested calibration maps each single lead's entropy and iteration count to midpoint empirical distribution values learned on LUDB. It sums these two values without further fitting. Matched-error status ignores unmatched events; the composite also classifies any missed or false annotation as an error. Zhejiang and ISP provide global delineation references projected across leads. Results use all 4,008 and 5,700 externally evaluable leads, respectively. Intervals condition on the trained model and internal reference frame and account for record, not training, variability. Comparisons against both raw entropy and reference-transformed entropy are in the CSV. Cohort-ranked AUCs reproduce the original point estimates. The composite analysis is exploratory and the uncertainty bounds are not multiplicity-adjusted.
